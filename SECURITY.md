# Security and privacy

Configuration files can specify local executables. They are not sandboxed: only
run configurations and checkers you trust. An argv array avoids accidental shell
interpolation; it is not a permission boundary. Explicitly configuring a shell
still runs that shell.

The demo is offline after explicit third-party media setup. X portrait resolution is opt-in, contacts Unavatar,
and sends public handles to that service. Cached images and prepared absolute
paths stay under the ignored `.cache/` directory. No passwords, cookies, API keys,
or X account session are requested. No telemetry is collected.

The popup opens only the URL in your config after accepting. Check it before
running downloaded configs. Only `codex:`, `https:`, and `http:` schemes are
accepted. Your availability checker is responsible for reliable access evidence
and provider usage controls; this project does not grant access or bypass limits.

Do not publish private credentials in an issue. Use GitHub private vulnerability
reporting if enabled, or contact the maintainer before disclosing sensitive data.
